# ABC College Website

A simple, responsive static college website built with **HTML, CSS, JavaScript & Bootstrap 5**.

## Pages
- `index.html` — Home (hero + carousel + features)
- `about.html` — About, Mission, Vision, Goals
- `courses.html` — Course cards (BCA, BBA, B.Com, BA, B.Sc, MCA)
- `faculty.html` — Faculty cards with photos
- `gallery.html` — Image grid with hover zoom
- `contact.html` — Contact form + Google Map

## Folder Structure
```
College-Website/
├── index.html
├── about.html
├── courses.html
├── faculty.html
├── gallery.html
├── contact.html
├── css/style.css
├── js/script.js
└── images/ (bg, slide1..5, college)
```

## How to Run
Just open `index.html` in a browser. No build step required.
Bootstrap & Font Awesome load from CDN (internet needed).

## Customize
- Change college name in each page's navbar + footer.
- Replace images inside `images/` with your own (same filenames).
- Primary color is `#0d6efd` — edit in `css/style.css`.
