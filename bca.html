Bachelor of Computer Applications (BCA)

Course Overview

BCA is a three-year undergraduate degree that provides knowledge of programming, databases, networking, web development, and software engineering.

Duration

3 Years (6 Semesters)

Eligibility

Passed 10+2 from a recognized board.

Subjects

  • C Programming
  • Python
  • Java
  • Database Management System
  • Web Development
  • Computer Networks

Career Opportunities

Software Developer, Web Developer, Data Analyst, System Administrator, IT Professional.
